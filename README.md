# Test for SESAC Assignment

## 프로젝트 소개

이 프로젝트는 SESAC 과제를 위한 테스트 저장소입니다. Git과 GitHub의 기본적인 워크플로우를 학습하고 실습하기 위한 목적으로 생성되었습니다.

## 프로젝트 목적

- Git과 GitHub의 기본 개념 이해
- 원격 저장소 클론 및 브랜치 관리 실습
- 문서 작성 및 커밋 워크플로우 경험
- 협업을 위한 Git 사용법 습득

## 학습 내용

이 프로젝트를 통해 다음 내용을 학습합니다:

1. **원격 저장소 관리**
   - 저장소 클론하기
   - 브랜치 생성 및 전환
   - 원격 저장소와의 연결 확인

2. **문서화**
   - 마크다운 문법 활용
   - README 파일 작성
   - 프로젝트 문서화 방법

3. **Git 워크플로우**
   - 변경 사항 확인 (`git status`)
   - 스테이징 (`git add`)
   - 커밋 생성 (`git commit`)
   - 원격 저장소 푸시 (`git push`)

## 실행 방법

현재 이 프로젝트는 학습 목적의 저장소이므로 특별한 실행 방법은 없습니다.

```

### 브랜치 생성 및 전환

```
